Why this two-step setup
This bookmark never needs to be re-dragged again. When the tool is updated, only bsra-bookmarklet.js on GitHub changes — the bookmark always pulls whatever is there the moment you click it (a cache-busting timestamp is added automatically so you always get the latest version, not a stale cached copy).
What it works out
• Aggregate Cup — total points with per-school ranking, split by Year 8 / 9 / 10 / Senior.
• Percentage Trophy — points ÷ enrolment, with the Cup winner excluded.
• First Eight (BSRA Trophy) — placing in the Open First Eight.
• Export — a printable summary report matching the official results sheet, built live from whatever has scored so far.
Scoring rules built in
• Points scale by boat: single 10→1, quad & four 50→5, eight 90→9.
• Only the first running of each event scores; quads score Div 1–4 only.
• Best crew per school counts, then crews are re-ranked among the nine BSRA schools.
• Crews marked [inv] (invitational) race but never score points.
• Keeps itself current — after the first pass it re-checks the schedule about once a minute and loads results as they’re published (new races included). A Refresh now button and an Auto-refresh toggle sit at the top of the panel, with a “last checked” time.
• Polite by design — races are fetched one at a time with a randomised 1.7–3.5 s gap, so the site only ever sees a slow trickle of requests.
• Enrolments are editable — in the Trophies tab, tap any # Students figure to change it. Values are saved in your browser and reused next time (with a Reset to defaults link).
