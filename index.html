Drag not working? Add it manually ↓
Bookmarks bar hidden? That's the most common cause — the button can only be dropped onto a visible bar. Show it with Ctrl+Shift+B (Windows/Linux) or Cmd+Shift+B (Mac), then try the drag again.
Still no luck (or on mobile)? Add it by hand instead — drag-to-bookmark isn't supported on phones/tablets at all:
  1. Click Copy bookmarklet code above.
  2. Create a new bookmark any way your browser allows (e.g. right-click the bookmarks bar → Add page…, or star a page then edit it, or use the bookmark manager's Add button).
  3. Set the bookmark's name to BSRA Points, and paste the copied code into the URL field (replacing whatever's there) — browsers sometimes trim a leading javascript: when pasted into a normal address bar, but the URL field of a bookmark editor keeps it intact.
  4. Save. Clicking that bookmark on the results page works exactly the same as the drag-and-drop version.

How this stays up to date
Some results sites (like rowingmanager.com) block pages from loading scripts hosted elsewhere, so the bookmark now carries the whole tool inside it rather than fetching it fresh each click. This installer page always pulls the current version from GitHub when you open it — so if bsra-bookmarklet.js changes, just reload this page and drag the button again to pick up the update.
What it works out
• Aggregate Cup — total points with per-school ranking, split by Year 8 / 9 / 10 / Senior.
• Percentage Trophy — points ÷ enrolment, with the Cup winner excluded.
• First Eight (BSRA Trophy) — placing in the Open First Eight.
• Export — a printable summary report matching the official results sheet, built live from whatever has scored so far.
Scoring rules built in
• Points scale by boat: single 10→1, quad & four 50→5, eight 90→9.
• Only the first running of each event scores; quads score Div 1–4 only.
• Best crew per school counts, then crews are re-ranked among the nine BSRA schools.
• Crews marked [inv] (invitational) race but never score points.
• Keeps itself current — after the first pass it re-checks the schedule about once a minute and loads results as they’re published (new races included). A Refresh now button and an Auto-refresh toggle sit at the top of the panel, with a “last checked” time.
• Polite by design — races are fetched one at a time with a randomised 1.7–3.5 s gap, so the site only ever sees a slow trickle of requests.
• Enrolments are editable — in the Trophies tab, tap any # Students figure to change it. Values are saved in your browser and reused next time (with a Reset to defaults link).
